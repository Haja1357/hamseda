# هم‌صدا

تخته ارتباطی کودک و همراه خانواده و مربی، به زبان فارسی. همه‌چیز روی دستگاه خود کاربر می‌ماند و به جایی فرستاده نمی‌شود.

- **نسخهٔ وب:** همین مخزن روی GitHub Pages منتشر می‌شود (`index.html`). بعد از اولین باز شدن، بدون اینترنت هم کار می‌کند.
- **نسخهٔ اندروید:** با هر تغییر، GitHub فایل `hamseda.apk` را می‌سازد و کنار نسخهٔ وب می‌گذارد. همهٔ فایل‌های برنامه داخل APK است و به سایت یا اینترنت نیازی ندارد.
- **کتابخانه‌ساز:** `builder.html`، برای ساختن بسته‌های محتوای تأییدشده.

ساخت اندروید: پوشهٔ `android/` و دستورالعمل `.github/workflows/android.yml`. کلید امضا رمزگذاری‌شده در `android/signing/` است و رمز آن فقط در Secrets مخزن (`SIGNING_PASSWORD`) نگه داشته می‌شود.

تصویرهای سه‌بعدی: Fluent Emoji از Microsoft (MIT). قلم‌ها: وزیرمتن و لاله‌زار (OFL). جزئیات در `LICENSES.txt`.
